<h1 align="center">
    Better Nationalization
</h1>

**Better Nationalization** is a Victoria 3 mod that removes infamy for war goal of forcing nationalization and enables nationalization even if you've entacted Laissez Faire.

## Supported Version

1.9.8 - 1.11.1
